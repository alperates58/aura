Canlı Sunucu İçin 5 Maddelik Operasyonel Kontrol Listesi

Yazılım kod tabanı tamamen hazırdır; canlı sunucuda (alperserver) aşağıdaki 5 maddenin teyit edilmesi puanı 9.5+ seviyesine çıkaracaktır:

1.
LiveKit Medya Portu (7881 UDP/TCP) UFW Kontrolü

Sunucu terminalinde ufw allow 7881/udp && ufw allow 7881/tcp komutunun çalıştırıldığından emin olun.

2.
Cloudflare Trusted IPs / DNS Proxy Modu

Cloudflare kullanılıyorsa DNS Only (gri bulut) tercih edilmeli veya Traefik'e Cloudflare IP listesi eklenmelidir.

3.
Docker Socket Yalıtımı Teyidi

Aura servislerinin hiçbirinde /var/run/docker.sock mount'u yoktur; Coolify ortamında bu durum korunmalıdır.

4.
PostgreSQL & Redis Dış Port Kapalılığı

5432 ve 6379 portlarının sunucu IP'sinden internete kapalı olduğu nmap ile teyit edilmelidir.

5.
Periyodik Bağımlılık Taraması

make audit komutu ile düzenli olarak paket güvenlik açıkları taranmalıdır.
